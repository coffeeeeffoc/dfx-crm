# 材料与原型对应

更新：2026-10-25 第二轮。依据为 19 张 Excel 工作表、28 张截图、3 份中文录音转录；原音总长 7236.598 秒。逐项来源和实现位置见 [材料核对表](materials-audit.md)，单元格坐标见 [Excel 提取](materials/workbook-audit.txt)。

优先级：当前用户要求 → Excel「确认内容」的明确答复 → 其他工作表和截图 → 录音讨论。历史材料中“全员看到所有客户”的说法已被本人及所有层级下属规则覆盖。共享库存、供应商、基础资料和已发布知识保留明确的共享阅读例外；共享不等于可修改。

## 可操作范围

- 销售：线索和客户 Excel 预览导入、查重、转项目、无机会线索直接入公共池、项目七阶段、独立签单概率、成单订单号、带原因放弃与领取、前负责人历史快照。
- 客户：主联系人、同单位多联系人及关系、个人/公共标签、开票寄送信息、下次跟进、删除/恢复。供应商支持多联系人；项目可关联供应商及其手册。
- 沟通：日期、方式、正文、附件、下一次计划；本人在可配置窗口内修正并保留旧版本；过期可补充，管理员可修正。默认 15 分钟是暂定值，并非材料确认的时长。
- 报价、合同、服务：报价多产品编码/型号/数量/价格/折扣/运保费；订单客户回款及供应商付款；合同、发票、物流、外贸、成本奖金补充字段；服务设备、工具、保修、培训、工程师、现场结果及附件。
- 库存：样机/研发/安装物料、编号、成本、地点、库存，借用协议、联系人、押金租金、寄还日期/运单/照片、归还登记和借还台账。其他团队借用详情不可见，只保留占用量供计算可用库存。
- 团队：学习档案分类、正文排版/预览、图片附件/视频链接、草稿→提交→主管审核→发布/退回；日/周/月/季/年工作日志，期间全部手填记录与销售/学习/服务/市场活动汇总。
- 新增页面：费用与成本、市场与行政、基础资料。费用将按员工展开列规范为“负责人、类别、日期、金额”明细；基础资料支持通讯录、汇率税率、常用文件等分类及附件。
- 工作台：年/月/周/日/自定义期间、本人/本人及下属；统计卡片明细图标、同范围弹窗和 Excel；转化、90%/100%阶段金额、来源/品牌、跟进和贡献指标。统计页保留表格/图表切换。
- 管理：企业名/Logo、用户增改删和业务交接、直属领导/组织树、内置及自定义角色、菜单/页面/弹窗/按钮/字段权限、动态字段停用恢复、字典、操作记录、JSON 备份。

## 统一查询与导出

业务记录统一登记创建人、创建时间、更新人、更新时间。保存入口自动盖戳；旧存档缺失信息显示“未记录”，不伪造。日期范围包含起止日。

业务页“筛选查询”支持负责人、创建人、更新人，业务日期、创建时间、更新时间范围；业务字段条件支持包含、等于、数字/日期范围，按“并且”组合。隐藏字段不进入选项；旧条件遇到权限变化拒绝匹配。人员候选来自当前可见记录。

主列表“显示更多字段”可选择补充字段和元信息。导出使用当前筛选后的记录 ID，重新执行数据范围及列表、来源区域、导出区域字段交集；支持自定义/补充字段。嵌套联系人、报价产品和借用记录脱敏后以 JSON 单元格导出。个人标签仅当前身份可见。无导出权限时隐藏按钮。

## 暂定口径及边界

1. 仅前端 Vite + React + antd + antd-mobile，本机浏览器存储和 IndexedDB；没有真实登录、后端、跨设备同步或服务器权限隔离。
2. 系统管理员查看全部；普通角色统一本人及递归全部下属，角色/部门名称不扩大范围，见 [权限说明](permissions.md)。
3. 工作台按记录自身创建/发生日期筛选，预期金额=预算×概率。转换用时只算有转换时间的样本；跟进时长为创建日至期间最近沟通。转出成单率只看当前授权记录和移交快照，不读取其他团队后来私有进展。
4. 复杂合同和财务字段以登记为主；合同产品明细为文字登记，报价为结构化多行。客户/供应商付款采用可追加记录，不限制为截图固定三/四/六行。附件共用附件区，未做签章、合同打印或专业文档编辑。
5. 外币汇率、税费、资金占用、奖金提成、租金逾期费未套用未经确认的结算公式。简单利润仅供演示；新增财务敏感字段默认对非管理员隐藏，需要明确授权。
6. Excel 导入仅 `.xlsx` 第一张表、最多 5000 行/10MB，支持客户及线索；非全量历史系统迁移。动态字段类型固定、停用保留数据；字典仍为追加模式。
7. 转录已保存但未逐字人工审校、未识别说话人。第 2 段三处异常保留标记；人物/品牌和结算规则需要业务复核。
8. 公共池交接有快照；直接改负责人即时改归属，不额外引入未确认审批。每个浏览器实例配置一个企业，正式多租户由后端实现。
