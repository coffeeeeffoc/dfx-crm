# 企业、角色、组织与字段

更新：2026-10-25 第二轮。以下是前端权限演示；完整数据仍保存在浏览器，不构成生产安全边界。

## 企业与角色

企业配置支持全称、简称、介绍、Logo（PNG/JPG/WebP，1MB），导航和标题同步。一个实例一个主体，未做跨企业登录。

内置 `sys_admin`、`sales_manager`、`sales`、`readonly`；可新增空角色或复制角色。自定义 code 为 2–48 位小写字母/数字/下划线，以字母开头，唯一且创建后固定；名称、说明、权限可改。用户绑定 roleId，新 code 无需额外业务分支。内置角色不能删除；被用户绑定的角色不能删除。每位用户一个角色。

系统管理员受保护；其他角色可配置。主管默认可分配、导出、审核，但不默认获得全部财务敏感字段。旧存档保留授权，新财务字段对非管理员默认隐藏；新菜单不会自动加入已有自定义角色。

## 授权层次

`menu.area.action` / `menu.area.fieldKey`：菜单 → 页面或子弹窗 → 操作与字段。已注册列表、详情、新增/编辑、沟通、沟通导出、订单收付款/成本利润、导出、统计明细、借用、归还。

| 层次 | 行为 |
| --- | --- |
| 菜单/区域 | 入口不可访问时，按钮和字段不能绕过 |
| 操作 | 查看、详情、新增、修改、删除/恢复、导入/导出、分配、领取、审核等独立授权 |
| 字段 | 继承、隐藏、只读、可编辑；保存剔除不可写字段，保留原只读/隐藏值 |
| 数据 | 普通用户本人及递归全部下属，再叠加明确共享阅读例外 |
| 导出/统计 | 同时满足列表及导出/统计字段；统计弹窗导出还要求统计区域可见 |

例如 `projects.detail.budget = hidden`、`projects.edit.budget = read`：列表可见预算、详情隐藏、编辑只读。区域配置是有意差异，各入口使用同一权限解释器；没有覆盖配置时继承列表。

联系人姓名/电话/邮箱/性别/地址、报价编码/型号/数量/单价、借用协议/联系人/押金/租金/附件等子字段均可控制。隐藏沟通正文同时隐藏修正历史与补充。关闭菜单的业务集合不参与其他页面统计。创建/更新元信息只读；衍生金额只用授权输入计算。

保存、业务弹窗、导出重新校验。切换身份关闭旧弹窗，过期身份/数据快照不能继续提交。

## 组织和共享例外

直属领导递归直到全部层级；同部门、同角色不自动授权。用户可新增、改名、改部门/角色/领导、停用、删除/恢复。拒绝领导成环、自我汇报及移除最后启用管理员。删除必须选择下属树外的启用承接人，交接业务与直属下属；历史创建人/沟通作者保留，恢复不撤销交接。

| 记录 | 可见范围 / 写入 |
| --- | --- |
| 私有线索、项目、报价、订单、服务、费用、活动、日志 | 本人及递归下属，另检查操作权限 |
| 公共线索/客户池 | 公共记录及相关历史可读；领取后归属新负责人；不公开同客户其他私有项目/沟通 |
| 历史移交 | 前负责人及上级只读移交前快照，不读后来的私有跟进 |
| 待分配线索 | 另要求分配权限 |
| 库存主档 | 共享阅读；编辑检查归属/操作。其他团队借用仅保留占用量，隐藏联系人、协议、寄还详情、附件；只能归还自己/下属借用 |
| 供应商、基础资料 | 按菜单共享阅读；基础资料默认仅管理员维护，供应商另检查归属/操作 |
| 已发布知识 | 按知识菜单共享阅读；草稿/审核按归属；修改发布内容退回草稿 |
| 个人标签 | 当前身份专属，不携带他人标签到列表、详情、筛选、导出 |

客户可因有权访问的关联项目而可见，不因此获得客户全部私有业务。演示组织不代表真实组织。

## 字段及导出

可新增文本/数字/日期/单选字段、改显示名、停用/恢复；key 和类型固定，必要身份/关联/归属字段保留。材料补充字段共用机制，位于“补充业务字段与自定义字段”。停用不清历史值。

列表、详情、编辑、筛选、Excel 查同一字段注册表。导出按筛选 ID 重新取授权记录，取列表∩来源区域∩导出区域可见字段；嵌套明细先脱敏，动态字段一起导出。整库 JSON 备份仅管理员可用，不含 IndexedDB 附件二进制，当前没有 JSON 恢复入口。

后端需不可变 userId/ownerId、tenantId、服务端递归范围和字段/附件/导出校验。原型仍以唯一姓名关联，改名同步业务；没有真实账号密码、多租户鉴权或多人并发保证。
