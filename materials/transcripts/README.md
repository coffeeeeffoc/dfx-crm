## 识别说明

- 使用本机 `faster-whisper` / Whisper large-v3-turbo，CUDA int8_float16，中文、beam_size=5，5 分钟切片，启用语音活动检测。
- 模型来自 `dropbox-dash/faster-whisper-large-v3-turbo`，固定 revision `0a363e9161cbc7ed1431c9597a8ceaf0c4f78fcf`。

## 复现

脚本在 `scripts/transcribe.py` 和 `scripts/recheck_transcripts.py`。需要 FFmpeg、支持 CUDA 的 PyTorch、faster-whisper、opencc-python-reimplemented，以及本机 NVIDIA GPU。首次运行会下载模型至 `.cache/`。本机使用 Python 3.10 / CUDA PyTorch 2.5.1；没有把转录运行时加入前端依赖。

```powershell
python scripts/transcribe.py
python scripts/recheck_transcripts.py
```

重跑会复用已完成切片并重新生成文本；需再次运行第二条命令应用异常片段的二次识别。
